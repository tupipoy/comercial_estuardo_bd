# PRoblemas solucionados con IA asi como la mejora del disenio de login y estructura 
| Problema / Solicitud | Prompt / Contexto | Diagnóstico y Solución Aplicada |
| :--- | :--- | :--- |
| `OperationalError: (2003, 'Can\'t connect')` | Error al intentar abrir `localhost:5050` tras iniciar Flask. | El daemon de MySQL no estaba ejecutándose; se aprovisionó con `brew install mysql` y `brew services start mysql`. |
| `Error 1146: Table 'rol' doesn't exist` | Inserción inicial de credenciales de usuario. | Inspección de catálogo mediante `SHOW TABLES`; se identificó que el modelo utiliza `EMPLEADO` vinculado a `SUCURSAL`. |
| `Error 1364 / 1054 en SUCURSAL` | Inserción de sucursal con campos faltantes o desconocidos. | Ajuste del `INSERT` con los campos exactos del esquema (`direccion`, `municipio`, `telefono`, `estado`). |
| Maquetación del Login | Interfaz de inicio de sesión sin estilos ni centrado. | Creación de layout flexbox en `style.css` con centrado vertical/horizontal y estilos modernos. |
